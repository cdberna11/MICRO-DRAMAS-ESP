Sin descargar ni modificar archivos en una computadora. Las imágenes se copiarán desde los archivos actuales de Cloudflare Pages hacia el bucket microdramas-portadas.

Esta operación no cambia Cloudflare D1 ni elimina ninguna portada de GitHub.

Etapa 3 · Guardar portadas nuevas exclusivamente en R2

      
Una vez cambiadas y comprobadas todas las referencias en D1, activa el destino de carga del panel administrativo. Esto no cambia el diseño del formulario y no toca la APK ni el reproductor.

      
El destino de subida sigue en GitHub hasta activar esta etapa.

      

        
      

      
Después de activar, prueba la subida de una portada de un borrador, confirma la nueva ruta /media/portadas/... y verifica cómo se ve en navegador de escritorio, móvil y APK.

    

    

      
Etapa 4 · Retirar portadas duplicadas de GitHub

      
La eliminación no está automatizada desde este panel. Se realizará mediante un commit específico en GitHub únicamente después de validar las imágenes reales en las tres plataformas. Se conservarán los logos, avatares y portada genérica.
